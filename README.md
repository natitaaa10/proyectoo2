# proyectoo2
Sistema de gestión de inventario para una ferretería.

- Francisco Javier Martínez López
- Alan Romero Ramírez
- Nataly Michell San Juan Ascención

## PROBLEMÁTICA
La ferretería presenta algunas dificultades para llevar un control adecuado de los productos disponibles, debido a que el registro del inventario puede realizarse de manera manual.
Esta situación puede ocasionar problemas como productos registrados incorrectamente, también la dificultad para conocer las existencias actuales, pérdida de información y retrasos al momento de consultar o actualizar el inventario. Por esta razón se propone desarrollar un sistema de software que permita administrar de manera organizada la información de los productosy facilitar el control del inventario.

## OBJETIVO
Desarrollar un sistema de gestión de inventario para una ferretería que permita registrar, consultar, actualizar y eliminar productos, así como controlar las existencias disponibles.
El sistema busca facilitar la administración de los productos, reducir errores en el registro de información y proporcionar una consulta rápida del inventario.

## ALCANCE
El sistema permitirá:
- Registrar productos.
- Consultar productos.
- Actualizar información de productos.
- Eliminar productos.
- Controlar las existencias de los productos.
- Buscar productos.
- Consultar información del inventario.
